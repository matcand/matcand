**Estudante de Informática para Negócios | Desenvolvedor Backend & UI/UX**

Sou um desenvolvedor focado em arquitetar soluções eficientes e desenhar interfaces intuitivas. Baseado em Diadema (São Paulo), dedico o meu tempo a aprofundar conhecimentos em engenharia de software, desde a modelagem de bancos de dados complexos até a implementação de pipelines de CI/CD e desenvolvimento de aplicações web (SPA). Acredito que o bom código nasce da união entre lógica rigorosa, segurança da informação e uma excelente experiência do usuário.

### 🔭 O que estou construindo e estudando agora:
- **Projeto de Graduação (FATEC):** Desenvolvendo uma plataforma para estágios baseada na compatibilidade de competências, focada no *match* exato entre o perfil técnico dos estudantes e os requisitos das empresas.
- **Formação Full Stack (DevClub - Certificado MEC):** Em aprimoramento contínuo nas bases do desenvolvimento web. Módulo de estruturação semântica com **HTML5** concluído e avançando atualmente no domínio de estilização e layouts responsivos com **CSS3**.
- **TCHOREGANG:** Projetando a arquitetura de UI/UX e as mecânicas de gamificação comunitária no Figma para uma plataforma mobile independente.
- **Gestão da Qualidade de Software:** Aplicando automação CI/CD, Git Flow e testes unitários avançados (JUnit, Mockito, BDD com Cucumber) em projetos corporativos.
- **Linguagens de Programação III:** Construindo aplicações web modernas e responsivas (SPA) com **Vue.js** e **Vite**, implementando arquitetura MVVM, manipulação dinâmica de componentes e gestão de rotas com Vue Router.
- **Sistemas de Segurança da Informação:** Praticando a gestão de segurança e auditoria, configurando ambientes locais seguros (Python/PyCharm) e realizando análises de logs corporativos em ferramentas DLP (Data Loss Prevention).
